# Datasets – Explainable Ensemble Fetal Health

This folder contains the datasets used in the **Explainable Ensemble Fetal Health** project.

The datasets are used for fetal health risk assessment, ultrasound analysis, image segmentation, and model development.

## Dataset Categories

| Dataset | Purpose |
|---|---|
| CTG | Fetal heart rate and uterine activity analysis |
| Ultrasound Planes | Fetal ultrasound view classification |
| IUGC Image | Fetal ultrasound image analysis |
| IUGC Video | Fetal ultrasound video analysis |
| Fetal Abdomen | Fetal abdomen segmentation |
| Fetal Head | Fetal head segmentation |

## Purpose

These datasets support different components of the project, including:

- Fetal health risk prediction
- Cardiotocography (CTG) analysis
- Ultrasound image analysis
- Ultrasound video analysis
- Fetal head segmentation
- Fetal abdomen segmentation

## Data Usage

The datasets are used for **academic research, experimentation, model development, and evaluation**.

Due to dataset size and licensing restrictions, the original dataset files may not be included in this GitHub repository.

Each dataset folder contains a separate README with information about the dataset, source, purpose, and usage.

## Dataset Sources and Licenses

The datasets belong to their respective original authors or organizations.  
Users should refer to the original dataset sources for access, licensing, citation, and usage requirements.
